**sentiment-analysis-CNN: Movie Review Sentiment Analysis using a Convolutional Neural Network (CNN) with TensorFlow and Keras.**

**Sentiment Analysis using CNN**

This project uses a Convolutional Neural Network (CNN) to predict whether a movie review is **positive** or **negative**. The model is trained using the IMDB Movie Reviews dataset available in TensorFlow/Keras.

**About the Project**

The project converts text reviews into numbers that the computer can understand. These reviews are then passed through a CNN model, which learns patterns in the text and predicts the sentiment.

**Features**

Predicts positive or negative reviews
Uses the IMDB movie review dataset
Built with TensorFlow and Keras
Shows training accuracy and loss graphs
Displays confusion matrix and classification report
Can predict sentiment for new reviews

**Dataset**

Dataset: IMDB Movie Reviews
Training samples: 25,000
Testing samples: 25,000
Two classes:
  1) Positive
  2) Negative

**Tools Used**

Python
TensorFlow/Keras
NumPy
Matplotlib
Scikit-learn

**How to Run**

**1. Clone the repository**

```bash
git clone https://github.com/your-username/sentiment-analysis-cnn.git
```

**2. Install the required packages**

```bash
pip install -r requirements.txt
```

**3. Open the notebook**

```bash
jupyter notebook
```

Run the notebook named:

```
Sentiment analysis CNN.ipynb
```
